How DocLens works

DocLens searches a pinned collection of official documentation and uses the retrieved passages to answer.

  • Assistant links each answer to its supporting passages and flags questions with insufficient evidence.
  • Retrieval lab runs keyword, vector, or combined search and shows the ranked passages.
  • Source library shows the document versions and licenses in the index.
